# TouchKeys V5.2

TouchKeys V5.2 refreshes the desktop monitor and simplifies the mobile controller experience. It does not change any actual functionality.

## Highlights

- Reworked the desktop monitor into a dark workspace with a compact command bar.
- Added a focused dashboard layout for server controls, QR connection access, status, and quick actions.
- Improved the layout editor workspace with clearer canvas, properties, and preset navigation.
- Fixed contrast for layout tabs, connected-device labels, kick actions, and tester button states.
- Made long monitor pages scroll correctly, including the editor and tester views.
- Moved mobile layout preset switching and connection status to the mobile home screen.
- Removed the mobile controller toolbar and bottom layout bar to keep the active controller view uncluttered.
- Preserved existing WebSocket control, streaming, layout import/export, tester, and QR workflows.

## Upgrade notes

1. Install or update the ViGEmBus driver if needed.
2. Download and launch `TouchKeys-V5.2.exe`.
3. Start the phone server from the desktop monitor.
4. Connect the phone and PC to the same Wi-Fi network.
5. Choose a layout preset on the mobile home screen, then tap **Start**.

## Release artifacts

- `TouchKeys-V5.2.exe` — standalone Windows application.
- `ViGEmBus_1.22.0_x64_x86_arm64.exe` — required virtual Xbox controller driver.
