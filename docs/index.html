NO CLOUD IN THE INPUT PATH

A short route
from touch to game.

Your PC hosts the controller page. Touch events travel back over a persistent WebSocket on your network, where TouchKeys turns them into Windows input.

FIRST SESSION

Three things
before you play.

Get the latest release ↗
01

Install TouchKeys

Download the current Windows release from GitHub and follow its included setup notes.

02

Add the gamepad driver

ViGEmBus is required for virtual Xbox controller output. Install it on Windows if it isn’t already present.

03

Connect your phone

Put both devices on the same Wi-Fi, start the phone server in the monitor, then scan its QR code. Your browser may ask you to trust the local certificate.
