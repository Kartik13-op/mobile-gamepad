How the Pipeline Works

Local Wi-Fi hosting communicates input state directly to Windows input drivers with standard WebSockets.

1

Local PC Server

TouchKeys starts a localhost monitor on port 8000 and an HTTPS server on port 8001.

localhost:8001
2

WebSocket Stream

Phone loads webpage via Wi-Fi and opens a persistent WebSocket connection back to PC.

ws://LAN-IP:8001
3

Input Handler

Touch data is processed into normalized analog stick values, trigger states, and button events.

vgamepad engine
4

Virtual Xbox Output

ViGEmBus driver creates a virtual Xbox 360 controller while PyAutoGUI handles KBM input.

ViGEmBus / PyAutoGUI

Important Anti-Cheat Advisory

TouchKeys utilizes the open-source ViGEmBus driver (the standard driver powering DS4Windows). Standard games and Easy Anti-Cheat (EAC) titles function smoothly, but exercise caution with titles enforcing strict ring-0 kernel anti-cheats (such as Valorant Vanguard).
