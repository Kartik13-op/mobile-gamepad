TouchKeys Mobile Controller

Transform your smartphone or tablet into a wireless PC gamepad and custom touch keyboard with zero configuration and ultra-low latency.

Download Standalone App (.exe)

Overview

TouchKeys is a high-performance desktop application designed for Windows that bridges mobile devices and PC games. By running a local FastAPI WebSocket server, TouchKeys instantly streams touch and sensor inputs from any smartphone web browser directly into virtual Xbox/PlayStation gamepad inputs on your PC.

Whether you want a portable controller for couch gaming, a macro pad for simulation games, or an extra gamepad for multiplayer sessions without buying additional hardware, TouchKeys delivers a seamless experience.

Key Features

  • Zero Installation on Mobile: No app stores or downloads required on your phone. Just scan the QR code or type your PC's local IP address into any mobile browser.
  • True Gamepad Emulation: Powered by the ViGEmBus driver and vgamepad, Windows detects your phone as a genuine hardware Xbox 360 controller compatible with 100% of controller-enabled PC games.
  • Ultra-Low Latency WebSockets: Persistent bidirectional WebSocket connection ensures instant input response with zero perceptible lag over local Wi-Fi.
  • Custom Layout Editor: Build and customize buttons, analog sticks, D-pads, triggers, and macros with a visual drag-and-drop editor.
  • Desktop Live Monitor: Watch live controller states and connected client sessions in real-time from your PC monitor.
  • 100% Standalone Executable: Single `.exe` package bundling Python, dependencies, DLLs, and web assets. No Python installation needed on the host PC.

Quick Start & Setup Guide

Step 1: Install the ViGEmBus Driver

TouchKeys requires the ViGEmBus kernel driver to emulate virtual gamepads on Windows. If not already installed, run the bundled driver installer:

installers\ViGEmBus_1.22.0_x64_x86_arm64.exe

Step 2: Run the Application

Download the standalone TouchKeys - Mobile Controller.exe and double-click to launch. The app starts a local server and opens the desktop monitor window automatically.

Step 3: Connect Your Phone

Make sure your phone and PC are connected to the same Wi-Fi network. Open the URL displayed in the console or desktop window (e.g., http://192.168.x.x:8000) on your mobile browser.

Technical Documentation & Architecture

TouchKeys is built using a modern, decoupled client-server architecture:

  • Backend: Python 3.13, FastAPI, Uvicorn (ASGI async server), and vgamepad interfacing with the ViGEmBus driver via ctypes.
  • Frontend: Vanilla JavaScript, HTML5, CSS3, and WebSockets providing a responsive mobile controller interface and live monitor dashboard.
  • Packaging: Bundled using PyInstaller into a single binary executable (`--onefile`) with isolated user data paths for configurations (`settings.json`) and layouts (`layout.json`).

API Endpoints

  • GET / — Serves the mobile controller interface (mobile.html).
  • GET /monitor — Serves the desktop live input monitor.
  • GET /api/ip — Returns the local network IP address.
  • GET /api/keys — Returns supported keyboard scan codes.
  • GET /api/clients — Returns active connected client sessions.
  • WS /ws — Bidirectional WebSocket channel for low-latency touch/axis events and layout synchronization.

Frequently Asked Questions (FAQ)

Do I need Python installed on my PC?

No! The standalone TouchKeys - Mobile Controller.exe includes a complete embedded Python runtime and all required packages.

Can I use multiple phones at the same time?

Yes, TouchKeys supports multi-client device slots and automatic controller promotion.

Why is my controller not recognized in games?

Ensure that the ViGEmBus driver is installed and that your game supports XInput (Xbox controllers).
